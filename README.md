# 12주차 실습 — CSV 데이터 정제 및 분석

## 1. 프로젝트 소개
pandas를 활용하여 성적 CSV 데이터를 정제하고, 반별·과목별 평균과 통계를 분석하는 프로그램을 작성하였다.

## 2. 실습 목적
데이터에 포함된 결측값, 중복, 공백, 비정상적인 점수를 제거하여 신뢰할 수 있는 분석 결과를 얻고, AI가 생성한 코드의 정확성을 검증하기 위해 작성하였다.

## 3. 구현 과정 및 실행 방법
- 명세서 작성 및 원본 데이터 진단
- 결측값, 중복 행, 불필요한 공백 및 범위 밖 점수 제거
- 필터링, 그룹화 및 통계 분석
- AI가 생성한 코드의 오류 발견 및 수정 요청
- 합계 일치, 개수 일치 및 스팟 체크
- 손계산과 pytest를 활용한 결과 검증

AI가 생성한 코드에서 필터링 과정 중 전체 데이터가 수학 데이터로 덮어써지는 문제를 발견하였다. 수정 프롬프트를 통해 필터링과 전체 데이터 분석에 사용하는 변수를 분리하였다.

## 4.데이터
- 원본 파일: scores_2026.csv
- 데이터 크기: 114행, 5열
- 인코딩: UTF-8
- 데이터 구성: 학번, 이름, 반, 과목, 점수
- CP949 인코딩 파일을 불러와 동일한 진단 결과가 나오는지 확인하였다.

| 정제 단계 | 남은 행 수 |
|---|---:|
| 원본 데이터 | 114 |
| 결측값 제거 | 108 |
| 중복 제거 | 104 |
| 공백 제거 | 104 |
| 범위 밖 점수 제거 | 100 |

## 5. 테스트 및 검증

### 손계산 검증
mini.csv를 활용하여 손계산 결과와 코드 실행 결과가 일치하는지 확인하였다.

- 정제 후 행 수: 7행
- 1반 평균: 80.0점
- 2반 평균: 70.0점

### pytest 자동 검증
- 정제 후 행 수 검증
- 반 종류 검증
- 그룹별 합계와 전체 합계 일치 검증
- 손계산 결과 일치 검증

| 실험 | 결과 |
|---|---|
| 정상 코드 | 4 passed |
| 공백 제거 코드 주석 처리 | 1 failed, 3 passed |
| 점수 범위를 0~1000으로 변경 | 1 failed, 3 passed |

공백 제거를 생략했을 때 반 종류가 3개로 나타났으며, 점수 범위를 변경했을 때 정제 후 103행이 남았다. 이를 통해 테스트가 오류를 정상적으로 검출하는 것을 확인하였다.

실험 후 코드를 정상 상태로 복구하였다.

## 6. 분석 결과

| 구분 | 1반 | 2반 |
|---|---:|---:|
| 전체 평균 | 78.24 | 71.44 |
| 수학 | 60.00 | 64.00 |
| 영어 | 76.00 | 79.00 |
| 프로그래밍 | 84.00 | 88.00 |

전체 평균은 1반이 높지만 과목별 평균은 모두 2반이 높았다. 이는 반마다 과목별 인원 분포가 다르기 때문이며, 심슨의 역설에 해당한다. 따라서 데이터를 분석할 때는 전체 평균뿐만 아니라 집단별 구성과 비교 기준도 고려해야 한다.
